# Lista de materiales

Precios no incluidos a propósito: varían por país y por momento.

| Cantidad | Elemento | Observaciones |
|----------|----------|---------------|
| 1 | ESP32 DevKit (30 o 38 pines) | Cualquier variante con GPIO 21/22 para I2C |
| 1 | Módulo GY-521 (MPU-6050) | Algunos traen un chip compatible; ver `cableado.md` |
| 1 | Pulsador | Opcional, para grabar sin computadora |
| 4 | Cables dupont hembra-hembra | O soldados, si el grupo ya sabe soldar |
| 1 | Cable USB de datos | Algunos cables solo cargan: si no aparece el puerto, probá otro |
| 4 | Tornillos autorroscantes M3 x 8 mm | Para cerrar la tapa |
| 1 | Cinta, abrazadera o precintos | Para fijar la caja al péndulo o a la viga |
| ~100 g | Filamento PLA | Caja, tapa y vigas de prueba |
| 1 | Hilo no elástico y una masa | Para el péndulo |
| 1 | Regla o cinta métrica, cronómetro | Para contrastar con el sensor |

Alimentación: por USB desde la computadora o desde una batería externa USB (power bank). No hace falta manipular baterías de litio sueltas.
