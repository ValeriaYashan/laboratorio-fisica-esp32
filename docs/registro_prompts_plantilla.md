## Reglas del curso

1. La IA propone, vos decidís: todo código que uses lo tenés que poder explicar.
2. Se verifica siempre con una prueba, con una medición o con una fuente.
3. Se cita el uso de IA en el informe.
4. No se pegan datos personales de nadie en una herramienta de IA.
